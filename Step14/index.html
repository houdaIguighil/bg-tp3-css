Chapitre 1 : HTML

HTML permet de créer la structure d'une page web. Il sert à organiser les titres, les paragraphes, les images et les liens.

Chapitre 2 : CSS

CSS permet de modifier l'apparence d'un site web. On peut changer les couleurs, les tailles, les espaces et la disposition des éléments.

Chapitre 3 : JavaScript

JavaScript ajoute des fonctionnalités aux pages web. Il permet de réagir aux clics et de rendre un site plus interactif.

HTTP permet la communication entre un navigateur et un serveur. Il sert à envoyer des requêtes et recevoir les pages web.
